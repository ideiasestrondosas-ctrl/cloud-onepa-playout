# Plano de Análise e Proposta - Graphics > Templates Tab

## 1. Análise da Situação Atual

### Graphics Editor > Templates Tab (Tab 3)
A tab "Templates" dentro do Graphics Editor é **muito básica**:
- Lista apenas os templates guardados na API
- Permite apagar templates
- Botão de refresh
- Mensagem "Create templates in the full editor" quando vazio
- **Não permite criar ou editar templates**

### Página Separada: /templates
Existe uma página completa de Templates em `/templates` que tem mais funcionalidades:
- Preset templates (Morning Show, Full Day, Loop Content)
- Criar, editar, eliminar templates
- Gerar playlists a partir de templates
- Estrutura de blocos (intro, content, commercial, outro, filler)

## 2. Proposta de Melhorias para Graphics > Templates Tab

### Opção A: Manter como está (-le only)
Manter a tab apenas para visualização e delete, com link para a página completa de Templates.

### Opção B: Adicionar funcionalidades básicas
Adicionar botão para criar novo template diretamente na tab.

### Opção C: Integração completa
Integrar as funcionalidades da página /templates dentro da tab do Graphics Editor.
